# Xirao's More Items and Blocks
## Abbreviation "XMIB"
## 简称 "XMIB"

Introduce  介绍
==============
This is a Fabric mod that aims to add more compressed items to Minecraft.
For example, a compressed wooden sword, a triple stone pickaxe, etc.

这是一个致力于为Minecraft添加更多压缩物品的Fabric模组，比如一重木剑，十重石剑等。


License  许可证
==============
This mod is licensed under the MIT license.

这个模组使用MIT许可证

Handbook  指南
=============
Drag this Mod into the "Mods" folder in the Fabric instance, and then start the game.

将这个Mod拖进Fabric实例中的"Mods"文件夹，随后启动游戏即可
